# 🎉 New Year 2026 Wishes Website

A beautiful, interactive New Year wishes website with personalized astrological predictions and dynamic visual effects.

## ✨ Features

- 🎵 **DJ-themed Design** - Professional blue gradient with musical elements
- 🔮 **Personalized Predictions** - Based on zodiac signs and birth dates
- 🌟 **Dynamic Visual Effects** - Animated lighting, floating orbs, and particles
- 📱 **Mobile Optimized** - Responsive design that works on all devices
- 💫 **Data Collection** - JSONBin.io integration for user data storage
- 🎯 **DD/MM/YYYY Format** - User-friendly date input format

## 🚀 Live Demo

Visit the live website: [https://saiprudhvi01.github.io/New-Year-Wishes/](https://saiprudhvi01.github.io/New-Year-Wishes/)

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations
- **JavaScript** - Interactive features and data handling
- **JSONBin.io** - Cloud data storage
- **Google Fonts** - Typography (Comfortaa, Pushster)

## 📱 How to Use

1. **Enter your name** in the input field
2. **Enter your birth date** in DD/MM/YYYY format
3. **Click "🎹 MIX MY 2026"** to reveal your personalized predictions
4. **Share** your results with friends and family!
